# AITM-SMB Glossary

This glossary is informative.

Canonical semantics are defined in `CANONICAL_CONCEPTS.md`.

| Term | Short meaning | Canonical source |
|---|---|---|
| Outcome | Measurable business result | `ontology/ONTOLOGY.md` |
| Capability | Stable organizational ability | `ontology/ONTOLOGY.md` |
| Current State | How a Capability operates now | `CORE_MODEL.md` |
| Target State | Required future behavior of a Capability | `CORE_MODEL.md` |
| Gap | Difference between current and required behavior | `CORE_MODEL.md` |
| Cause | Condition explaining a Gap | `diagnostics/ROOT_CAUSE_ANALYSIS.md` |
| Intervention | Design choice intended to close a Gap | `CORE_MODEL.md` |
| Initiative | Executable package implementing Interventions | `CORE_MODEL.md` |
| System Constraint | Main current limiter of a target Outcome | `design/CONSTRAINT_ANALYSIS.md` |
| Constraint Migration | Movement of the limiting condition after change | `design/CONSTRAINT_ANALYSIS.md` |
| Target Operating Architecture | Integrated future operating system | `design/TARGET_OPERATING_ARCHITECTURE.md` |
| AI Suitability | Whether probabilistic intelligence adds structural value | `diagnostics/AI_SUITABILITY.md` |
| Autonomy | Authority granted to AI to act | `diagnostics/AUTONOMY_SUITABILITY.md` |
| Authority Ceiling | Maximum approved AI autonomy | `diagnostics/AUTONOMY_SUITABILITY.md` |
| Evidence | Source supporting a claim | `evidence/EVIDENCE_STANDARD.md` |
| Evidence Debt | Known evidence gap affecting a decision | `evidence/EVIDENCE_STANDARD.md` |
| Pilot | Bounded operational test of a transformation hypothesis | `execution/PILOT_MODEL.md` |
| Rollout | Controlled expansion of validated change | `execution/ROLLOUT_MODEL.md` |
| Value Realization | Observed and sustained business value | `measurement/VALUE_REALIZATION.md` |
