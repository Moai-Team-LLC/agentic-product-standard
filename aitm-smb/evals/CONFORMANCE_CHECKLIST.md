# AITM-SMB Conformance Checklist

## Traceability

- [ ] every selected Initiative links to an Outcome
- [ ] every selected Initiative links to a Capability
- [ ] every selected Initiative closes one or more Gaps
- [ ] every Gap has Evidence or explicit Hypothesis status
- [ ] every Initiative has success Metrics
- [ ] Target State is explicit

## Intervention quality

- [ ] non-AI alternatives were considered
- [ ] AI intervention type is explicit
- [ ] autonomy level is justified
- [ ] authority is explicitly granted, not inferred

## Evidence

- [ ] facts and assumptions are separated
- [ ] material claims have evidence
- [ ] missing baselines are visible
- [ ] causal uncertainty is visible

## Governance

- [ ] owner exists
- [ ] approvals are explicit
- [ ] escalation is explicit
- [ ] failure ownership is explicit
- [ ] recovery or rollback is defined where relevant

## Measurement

- [ ] business metric exists
- [ ] operating metric exists where useful
- [ ] AI metrics do not replace business metrics
- [ ] post-implementation evidence can change prior decisions
