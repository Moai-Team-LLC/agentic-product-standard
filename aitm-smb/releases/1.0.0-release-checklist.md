# AITM-SMB 1.0 Release Checklist

Status is generated and verified in `audits/1.0_RELEASE_AUDIT.md`.

The 1.0 release requires:

- one canonical source per stable concept;
- zero broken Markdown references;
- zero active skill references to deprecated artifacts;
- all active skills compatible with framework 1.0.0;
- all canonical artifacts versioned for 1.0.0;
- all five Application Profiles present;
- Core semantic trace intact;
- Capability Target State distinct from Target Operating Architecture;
- AI Suitability distinct from AI Authority;
- deprecated artifacts retained only as redirects;
- Core and Full distributions generated.
