# AITM-SMB Artifact Contract

Canonical artifacts SHOULD contain machine-readable metadata.

```yaml
artifact:
  type:
  id:
  framework_version: 1.0.0
  status: draft | reviewed | approved | superseded
  owner:
  upstream: []
  downstream: []
  evidence: []
  assumptions: []
  decisions: []
  open_questions: []
```

## Required semantic sections

Where relevant:

1. Purpose
2. Scope
3. Inputs
4. Content
5. Evidence
6. Assumptions / Hypotheses
7. Decisions
8. Open Questions
9. Validation
10. Change History

An AI-generated artifact is not approved merely because it exists.
