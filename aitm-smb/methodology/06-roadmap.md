# Phase 6 — Transformation Roadmap

## Objective

Move from Current State to Target Operating Architecture through bounded transition states and executable transformation slices.

## Required inputs

- approved Target Operating Architecture;
- selected Initiatives;
- Capability Network;
- System Constraint;
- uncertainty and risk records.

## Method

Use:

1. `transition/TRANSITION_STATE_MODEL.md`
2. `transition/TRANSFORMATION_SEQUENCING.md`
3. `portfolio/TRANSFORMATION_PORTFOLIO.md`
4. `execution/DELIVERY_SLICE.md`
5. `execution/EXECUTION_GATE_MODEL.md`

## Activities

1. map dependencies;
2. create Transition States;
3. define vertical transformation slices;
4. define execution gates;
5. identify where experiments or pilots are required;
6. define evidence each slice must produce;
7. sequence authority increases;
8. build Transformation Portfolio;
9. define rollback/recovery;
10. bound transformation WIP.

## Outputs

- Transition States;
- Transformation Roadmap;
- Transformation Portfolio;
- Delivery Slices;
- Execution Gates;
- pilot/experiment requirements.

## Exit condition

Roadmap is execution-ready when every material Initiative has:

```text
owner
bounded scope
dependency context
evidence plan
execution gates
rollback/recovery
success metrics
```
