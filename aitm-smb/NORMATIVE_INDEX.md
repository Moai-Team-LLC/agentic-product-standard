# AITM-SMB Normative Index

**Version:** 1.0.0

## Normative precedence

When documents conflict:

```text
1. Explicit approved human decision for the engagement
2. STANDARD.md
3. CORE_MODEL.md
4. TRACEABILITY.md
5. EXECUTION_MODEL.md
6. DECISION_MODEL.md
7. CONFORMANCE.md
8. AGENTS.md
9. Activated method module
10. Artifact contract
11. Skill
12. Informative guidance
```

Lower-priority material MUST NOT override higher-priority semantics.
